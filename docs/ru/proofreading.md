# Вычитка текста (октябрь 2026)

Проверен весь текст игры: реплики NPC, финал, титры, названия уровней, меню,
экран опций и строки, спрятанные в коде. Здесь — что исправлено и почему.
Предложения по улучшению текста (стиль, «ё», смысловые правки) вынесены
отдельно, решение по ним принимает автор перевода.

## Как проверялось

1. **Инвентаризация.** Помимо `assets/text/*.txt`, весь ROM просмотрен на
   участки, которые декодируются в русские слова. Нашлись строки в коде
   (`ПАУЗА`, `ТЫ ПОГИБ`, `МАРШРУТ`, сложность, кнопки, `НАЖМИ СТАРТ 2`,
   `ОЧКИ`/`ЭТАП`, `1Р 2Р КОМ`) и короткие подписи опций (`МУЗ`, `СЕ`,
   `А В С`). Каждая подтверждена инструкцией `lea`, которая её загружает, и
   циклом вывода; теперь они размечены в `rom_map.yml` и лежат в
   `assets/text/code_main_*.txt`.
2. **Таблица символов.** Каждая буква сверена с высотой своего глифа. Метки
   `0x29` и `0x50` были перепутаны: в файлах стояло «следуЮщий», «МЕНю», хотя
   в игре всё выводилось правильно. Исправлено, тест следит за этим.
3. **Вычитка** настоящего текста (`prose` в `rom_map.yml`) вручную: орфография,
   пунктуация, кавычки, смысл. Механические ошибки ловит `ga3 text lint`.
4. **Проверка в игре.** Все 16 реплик NPC показаны в эмуляторе: в копии ROM во
   временной папке первый указатель таблицы реплик (`0EBB42`) направлялся на
   нужную реплику. Заголовки всех реплик сверены с числом строк (тест).
   Финал до эмулятора не доведён — для него `ga3 text preview`.

## Исправлено

| Где | Было | Стало | Почему |
|---|---|---|---|
| реплика 1, `0EBC06` | `Эя все еще Жив!` | `'Я все еще жив!` | байт `0x22` рисует «Э», а не кавычку: переводчики ставили `"`; «Жив» — заглавная посреди фразы |
| реплика 1, `0EBC17` | `Не волнуйся, я разЪярЁн!` | `Не волнуйся, я разберусь` | фраза продолжается «со всеми врагами в округе»; «разЪярЁн» внесла правка этого проекта (демонстрация букв Ъ и Ё) и сломала предложение. Восстановлен текст переводчиков |
| реплика 1, `0EBC41` | `в округе.Э` | `в округе.'` | та же «Э» вместо кавычки |
| реплика 1, заголовок `0EBC05` | `02` (3 строки) | `03` (4 строки) | окно показывало 3 строки из 4: «в округе.» не выводилось никогда, фраза обрывалась |
| реплика 8, `0EBE8C` | `Спасибо тебе'` | `Спасибо!'` | нет знака в конце реплики; `Спасибо тебе!'` не помещается (строка 13 байт), «тебе» убрано |
| финал, `017AAB` | `Прошли годы и эта история стала` | ` Шли годы, и эта история стала ` | запятая между частями сложносочинённого предложения с разными подлежащими; строка занята целиком, «Прошли» → «Шли» освобождает место, пробел по краям сохраняет центровку |

Проверено и оставлено как есть:

- английские тексты — лицензия SEGA (`0136BA`) и сообщение о региональной
  блокировке (`013DD0`): стандартный текст SEGA, ошибок нет;
- «2003 NEWGAME» на заставке, все названия уровней, пункты меню, строки в коде —
  ошибок в написании нет (вопросы стиля — в предложениях);
- дефис вместо тире («осторожен - здесь») — тире в шрифте нет, дефис с
  пробелами — принятая замена;
- «все еще», «Темные», «наберешься» без «ё» — допустимо по правилам, строчной
  «ё» в шрифте нет (см. предложения).

## Решения по предложениям (12 октября 2026)

Все 17 предложений приняты. Внесено:

| Пункт | Стало |
|---|---|
| Строчная «ё» | глиф в слоте `0x3C` (шрифт 834 из 840 байт); «Вперёд», «всё ещё», «Тёмные», «мёртвых», «возведённый», «наберёшься», «придётся» |
| Строчная «ъ» | не рисуется: в тексте не встречается |
| «я разберусь» | оставлено |
| «Топора!!» | «Топора!» |
| «Победил ИГРОК 1/2.» | «Победил игрок 1/2.» |
| «оппонентов» | «соперников» |
| «невечен» | «не вечен» |
| «Без Золотого Топора, вечный мир» | без запятой |
| кавычки в названиях уровней | убраны у всех, названия заново отцентрованы в 20 символах |
| «НОРМА / ТРУДНО» | «ОБЫЧНО / ТРУДНО» |
| «МУЗ» / «СЕ» | «МУЗ.» / «ЗВУК»: таблица экрана опций переложена, три лишних хвостовых пробела отданы подписям |
| «НАЖМИ СТАРТ 2» | «ИГРОК 2: СТАРТ» — проверено в игре: мигает на экране выбора героя в дуэли, зовёт второго игрока вместо компьютера |
| «Планировщик», «Сообщения» | «Геймдизайн», «Тексты» |
| «Шли годы, и…», «Спасибо!'», дефис | оставлено как в ветке |
| меню «ВДВОЕМ» | по комментарию: «1 ИГРОК / 2 ИГРОКА / ДУЭЛЬ / ОПЦИИ» (ширина пунктов 8 — отдельный патч кода меню); «ДУЭЛЬ» без «ИГРОКОВ», потому что в дуэли бывает компьютер |

Проверено в эмуляторе: экран опций, вступление, реплики 1, 9, 11, 13, 15, выбор
героя в дуэли. Названия уровней, финал и титры — через `ga3 text preview`.
